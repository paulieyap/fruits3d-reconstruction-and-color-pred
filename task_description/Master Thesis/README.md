# Master Thesis Task Description #
This is a letter template for submission of a Master Thesis work task.

## How to start
- In GitLab:
  - Fork this repo into YOUR personal workspace (you will be asked)!
  - Change the name of the project: "Settings" -> "General project" -> "Project name" : `<student_name><year>msctask`.
  - Change the url of the project: "Settings" -> "Advanced" -> "Rename repository" -> "Path" : `<student_name><year>msctask` (same as above)
  - Remove fork relationship: "Settings" -> "Advanced" -> "Remove fork relationship". If you don't do this, the next time you fork this template it will not work, because a fork relationship already exists in the workspace.

- In your computer:
  - If all of the above was done, you can now happily clone and edit.
  - Go into the Makefile and change the 3 required fields:
    - STUDENT: Full name of student
    - THESIS: Full title of thesis
    - COSUPERVISOR: Your name
  - Write the task description in the `task.tex` file. This is usually done by the student to make sure they understood the task, reviewed by the co-supervisor (you), and finally checked and signed by Cyrill, who is always the main supervisor.
  - Once this is done, submit to Binnenbruck, and the student has then 4 to 6 months to finish thesis. Also submit [this document](https://gitlab.ipb.uni-bonn.de/ipb-team/global/wiki/blob/master/teaching/340-20162-m29-meldung-fuer-die-ausgabe.pdf).
